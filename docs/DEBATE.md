## UX Critic

### รอบ 1 — @reviewer

- **U1** parser ตัดเหลือบรรทัดแรก (L2) — regex ใช้ `$` + flag `m` ที่ `src/lib/profile.ts:42` → Interests แสดงแค่ ".NET" · Bio ได้ย่อหน้าแรก (ประโยค "ติดต่อได้ทางอีเมลด้านล่าง" หาย) — ต้องแก้ก่อนคุย IA
- **U2** parser ไม่อ่าน `## Contact` → อีเมลไม่ขึ้นที่ใดเลย · ฟอร์มยิง `POST /api/contact` ที่ยังเป็น stub → ผู้เยี่ยมเห็น "Error: NOT_IMPLEMENTED…" — ช่องทางติดต่อเดียวใช้ไม่ได้
- **U3** ข้อความเทคนิคหลุด: "ฟอร์มนี้โพสต์ไปที่ POST /api/contact", `/api/guestbook`
- **U4** ภาษาปน — nav/ปุ่ม/label อังกฤษ เนื้อหาไทย
- **U5** ธีมมืด ขัด Tone "สว่าง มินิมอล"
- **U6** IA: Home = Tagline → Headline → Proof → CTA + Services 2 การ์ด · About = Bio "ผม" + วิธีทำงาน + tech stack · Interests = แต่ละข้อมีคำอธิบาย 1 บรรทัด · Contact = อีเมล + ฟอร์มที่เลือกประเภทงาน (ใส่บรรทัดแรกของ message)
- **U7** Microcopy: ปุ่ม "ส่งข้อความ" · สำเร็จ "ได้รับแล้ว ผมจะตอบกลับภายใน 2 วันทำการ" (เฉพาะถ้าทำได้จริง) · error "ส่งไม่สำเร็จ ลองอีกครั้ง หรืออีเมลถึงผมโดยตรง" ห้ามโชว์ error ดิบ · placeholder "เล่าโปรเจกต์สั้น ๆ: ระบบอะไร · กรอบเวลา" · ตัด "อัปเดตเร็ว ๆ นี้"

### รอบ 1 — @reviewer

ความเสี่ยง (เรียงความรุนแรง):

- **R1 [Must]** Guestbook ต่อ `innerHTML` จากข้อมูลผู้ใช้โดยไม่ escape → stored XSS + ไม่มี anti-spam — บนเว็บที่ขาย "ปลอดภัยก่อนส่ง" = แบรนด์พังทันที

- **R3 [Must]** Privacy — อีเมล plain text โดน scrape · ถ้า repo public, Brainstorm/อีเมลใน `docs/` อ่านได้ · Dockerfile copy `docs/` ลง image
- **R4 [Should]** Overclaim — "10 ปี" / security / AI ยังไม่มีหลักฐานบนเว็บ
- **R5 [Should]** Projects อาจหลุดชื่อ/ช่องโหว่ลูกค้า ขัด "หลีกเลี่ยง" ใน Brainstorm เอง
- **R6 [Should]** Contact ตอบ 501 ถ้า ship ก่อน backend · ไม่มีนโยบายเก็บ/ลบข้อมูล (PDPA · L7)
- **R7 [Nit]** Scope creep — Services/Projects/tech stack/ประเภทงาน ต้องเพิ่มหัวข้อ + แก้ parser พร้อมกัน

คำถามก่อน ship: **Q1** ลูกค้าเข้า 30 วินาทีรู้ไหมว่าจ้างทำอะไร ราคาประมาณไหน ติดต่อทางไหน · **Q2** หลักฐาน "ปลอดภัยก่อนส่ง" ที่ไม่ละเมิด NDA · **Q3** repo public ยอมไหม · **Q4** ใครตอบอีเมล ภายในกี่วัน · **Q5** ผ่าน build/test และใครตรวจ meta/501
